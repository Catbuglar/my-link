# 마이링크 (MyLink) - 사용자 시나리오 (User Scenarios)

## 1. 소유자 (Owner) 시나리오

### 1.1. 가입 및 온보딩 (초기 진입 상태)
- 사용자는 **자신의 링크 페이지를 생성하기 위해** 서비스 메인 랜딩 페이지에서 [구글 소셜 로그인 버튼]을 클릭한다.
- 사용자는 **본인에게 할당된 고유 접속 주소(`mylink.com/displayName`)를 파악하기 위해** 최초 가입 시 지메일 아이디를 기반으로 자동으로 생성된 상단의 닉네임을 확인한다.
- 사용자는 **자신의 페이지가 현재 비어 있음을 인지하고 서비스 사용법을 익히기 위해** 링크 목록이 0개일 때 노출되는 초기 빈 상태 안내(Empty State) 문구("아직 등록된 링크가 없습니다. + 버튼을 눌러 추가하세요")를 확인한다.

### 1.2. 프로필 (소개글 및 닉네임) 관리
- 사용자는 **화면에 표시될 실제 닉네임(겸 접속 URL Slug)을 변경하기 위해** 상단의 `displayName` 텍스트를 스스로 직접 클릭하여 발생하는 인라인(Inline) 포커스로 텍스트를 수정하고 엔터(적용)를 친다. *(이때 주소(URL)도 함께 변경된다는 툴팁을 인지한다)*
- 사용자는 **자신을 방문자에게 명확히 소개하기 위해** 프로필 설명칸 영역 텍스트를 클릭하여 인라인으로 한 줄 소개를 작성(수정)하고 저장한다.
- 사용자는 **너무 긴 프로필 소개 내용이 사용자 디자인을 해치는 것을 막기 위해** 시스템이 정해둔 최대 글자 수를 초과 입력 시 발생하는 입력 제한/에러 메시지를 확인한다.

### 1.3. 링크 항목 관리
- 사용자는 **방문자에게 공유하고 싶은 외부 외부 서비스 주소를 보여주기 위해** [+ 링크 추가] 기능을 뜻하는 버튼(또는 더하기 아이콘)을 클릭한다.
- 사용자는 **새로운 링크의 세부 정보를 등록하기 위해** 목록 하단에 새로 만들어진 인라인 입력 줄에 이동할 화면의 [제목]과 [URL] 정보를 입력한다.
- 사용자는 **오류가 있는 링크가 노출되는 것을 방지하기 위해** 프로토콜(http/https) 형식이 어긋난 무효한 URL을 입력하고 저장 버튼을 눌렀을 때 나타나는 폼 검증(Validation) 경고 텍스트를 알아챈다.
- 사용자는 **자신의 링크를 시각적으로 돋보이게 나타내기 위해** URL 입력 성공 시 (Google API를 통해) 자동으로 삽입되는 외부 서비스 원본 파비콘(Favicon)을 확인한다.
- 사용자는 **기존 등록한 링크의 잘못된 URL이나 제목 오타를 빠르게 고치기 위해** 등록 완료된 링크 텍스트를 마우스로 다시 클릭하여 인라인 수정 모드로 만들어 즉시 내용을 바꾼다.
- 사용자는 **만료된 이벤트처럼 더 이상 필요 없는 기존 링크 항목을 삭제하기 위해** 해당 링크 우측에 위치한 [쓰레기통(삭제)] 버튼을 클릭하고 (안전장치 팝업 확인 후) 리스트에서 반영구적으로 제거한다.

### 1.4. 자신의 링크 통계 분석 (Analytics 기능)
- 사용자는 **자신의 어떤 콘텐츠/채널에 사용자들이 많이 유입되었는지 유효성을 파악하기 위해** 대시보드 화면상에서 본인이 등록한 개별 링크마다 카운트된 [누적 클릭 클릭수 통계치] 수치를 확인한다.

### 1.5. 로그아웃 및 페이지 공유
- 사용자는 **설정을 마친 내 마이링크 랜딩 페이지를 인스타그램 프로필 등 타 SNS에 업로드하기 위해** 주소 표출 패널 옆에 위치한 [주소 복사 버튼]을 클릭하여 클립보드에 URL을 복사한다.
- 사용자는 **보안 및 개인정보 관리를 위해** 화면 한쪽에 제공되는 [로그아웃] 버튼을 클릭해 작업을 종료한다.

## 2. 방문자 (Visitor) 시나리오

### 2.1. 정상 방문
- 방문자는 **소유자의 모든 정보를 한눈에 알아보기 위해** 오프라인이나 SNS 상에서 전달받은 `mylink.com/displayName` 주소를 주소창에 치거나 링크를 눌러 접속한다.
- 방문자는 **해당 프로필 페이지의 주인이 누구인지 식별하기 위해** 최상단에 있는 닉네임과 한 줄 요약 소개글을 눈으로 확인한다.

### 2.2. 외부 링크 탐색 및 상호작용
- 방문자는 **자신이 둘러보고 싶은 목적지를 구별하기 위해** 한눈에 보기 좋게 정렬된 링크들의 [제목] 텍스트와 [파비콘 썸네일] 이미지들을 스크롤하며 둘러본다.
- 방문자는 **소유자의 깃허브, 쇼핑몰 혹은 또 다른 소셜 네트워크 앱으로 이동하기 위해** 관심 있는 항목의 링크 버튼(카드 형태 등)을 손가락으로 터치(또는 마우스 클릭)한다.
- 방문자는 **이동이 원활하게 성공하였음을 확인하기 위해** (보이지 않는 백그라운드에서 조회수가 1올라감과 동시에) 클릭 즉시 소유자가 사전에 지정해 둔 해당 타겟 외부 웹사이트로 리다이렉트되어 진입한다.

### 2.3. 에러 사이트 처리 (예외 상황)
- 방문자는 **입력한 주소가 잘못되었음을 확실하게 인지하고 서비스 메인화면으로 복귀하기 위해** 존재하지 않거나 오타가 난 닉네임 주소(`mylink.com/아무개`)로 접속을 시도했을 때 뜨는 [404 Error: 페이지를 찾을 수 없습니다] 에러 안내 메시지와 홈(Home) 이동 버튼을 체험한다.
