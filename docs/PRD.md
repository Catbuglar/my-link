# 마이링크 (MyLink) - 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 개발자 및 크리에이터가 자신의 주요 작업물, 포트폴리오, 소셜 채널 등의 링크를 하나의 통합된 마이크로 랜딩 페이지로 모아서 공유할 수 있게 해주는 필수 기능 중심의 실용적인 서비스입니다.
- **대상 사용자**:
  - 기술 블로그, 깃허브(GitHub), 포트폴리오 등을 한곳에 모아 보여주고 싶은 **개발자**
  - 여러 활동 채널을 깔끔하게 하나로 모으고 싶은 **크리에이터**
- **기술 스택 정책**:
  - UI/UX 스캐폴딩으로 **shadcn/ui** 사용 (별도의 커스텀 테마 제공하지 않음)
  - 사용자 인증 및 계정 관리로 **Firebase Google 소셜 로그인 전용** 사용
  - 데이터베이스로 **Firestore(NoSQL)** 사용

---

## 2. 필수 핵심 기능 (MVP)
*주의: 서비스의 목적성을 강화하고 복잡도를 낮추기 위해 불필요한 기능(이미지 업로드, 테마 변경, 링크 순서 변경 등)을 일체 제거하고 가장 빠르고 직관적인 기능만 구체화하였습니다.*

### 2.1. 인증 및 사용자 식별 (URL Slug)
- **Google 소셜 로그인** 방식만 제공
- **URL Slug 할당 규칙**: 
  - 기본적으로 구글 로그인 시 사용한 **지메일(Gmail) 아이디의 앞 부분(아이디 부분)**을 추출하여 **`displayName`** 값으로 자동 설정합니다.
  - 이 `displayName` 값이 곧 커스텀 URL 식별자(Slug)로 사용됩니다. (예: `mylink.com/displayName`)

### 2.2. 관리자 대시보드 (설정 화면)
- 별도의 폼(Form) 화면이나 모바일 미리보기 패널을 두지 않고, 본인의 프로필 화면에서 직접 텍스트를 수정하는 인라인 편집을 지향합니다.
- **프로필 정보 수정**
  - (제외) 별도의 커스텀 프로필 이미지 업로드 기능 미제공 (기본 아이콘 설정 활용)
  - **인라인 편집(Inline Edit)**: 텍스트를 클릭하면 즉시 수정할 수 있는 입력창으로 바뀌며, 프로필(소개글) 및 사용자 이름이자 URL Slug인 **`displayName`**에 대한 인라인 수정 기능을 제공. (*참고: displayName 변경 시 본인의 접속 URL도 함께 변경됨*)
- **링크 관리 기능**
  - 링크 새 항목 **추가** 및 기존 링크 **삭제** 기능만 제공.
  - 추가/생성된 링크의 내용(제목, URL) 변경 시 **인라인 편집(Inline Edit)** 로직을 사용하여 해당 위치에서 바로 수정 동작 수행.
  - (제외) 링크 순서 변경, 테마 디자인 컬러 변경, 임시 노출 활성화/비활성화 스위치 제공 안 함.

### 2.3. 퍼블릭 프로필 뷰 (사용자 방문 화면)
- 타인이 방문 시 보이는 실질적인 랜딩 페이지, `shadcn/ui` 기반의 고정된 깔끔한 단일 UI (테마 선택 불가능).
- **자동 파비콘 썸네일 표시**
  - 등록된 각 링크 항목 옆에는 해당 URL의 아이콘인 **파비콘(Favicon)**을 표시합니다.
  - 파비콘 조회는 **Google Favicon API**(`https://s2.googleusercontent.com/s2/favicons?domain=...`)를 사용하여 추출 및 출력합니다.

### 2.4. 데이터베이스 구조 (Firestore 모델링 요건)
- **사용자(User) 문서**
  - 사용자의 노출 이름이자 **고유 URL Slug 식별자**로 사용되는 `displayName` 필드 필수 포함 (최초 로그인 시 이메일 앞부분으로 자동 할당).
  - 프로필 소개글(Bio) 필드 포함.
- **서브 컬렉션(Sub-collection) 활용**: 모델의 계층 구성을 위해, 사용자가 등록한 여러 링크 도큐먼트는 최상단 루트 컬렉션이 아닌, 해당 사용자 문서 내부의 하위 **서브 컬렉션(links)**으로 저장하여 응집력 있게 관리합니다.

- **링크 클릭 조회수**: 개별 링크의 누적 클릭 통계를 측정할 수 있는 데이터 로깅 시스템 및 노출 기능 (이번 초기 개발 스펙에는 절대 포함하지 않음)
